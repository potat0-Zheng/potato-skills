# CONTRACT-joint —— 三技能联合报告协同契约（v0.1）

> 单一事实源：百宝袋（bai-bao-dai）× 揽风云（lan-feng-yun）× 破虚妄（po-xu-wang）三技能联合任务
> 的**衔接约束**。各技能内部语义留在各自 SKILL.md；独立使用路径不加载本文件、零影响。
> 入口工作流关系见 skills/san-he-yi/SKILL.md（薄入口只讲顺序，不重复本文件细则）。

## 1. 硬性流程（禁止绕过流水线）

- 联合任务必须真实执行百宝袋流水线：`collect → normalize → (check 事实还原) → opinion`，再由 `build_report` 装配。
  **禁止以 LLM 手写 HTML 顶替流水线**；各步以文件参数串联，后一步输入缺失即停。
- 三平台（知乎 + 微博 + 小红书）真实采集为硬性要求；不得以"搜索摘要足够 / 抓取受限 / 估计网络不通"静默降级。
- 阻隔分类码：`P` 权限 / `C` 凭证 / `E` 环境。
  - P → 以 `danger-full-access` 升级重试同一条命令或向用户申请授权；
  - C → 向用户索取（扫码登录 > cookie），成功后重跑；
  - E → 如实报告 + 给出替代路径（dsh-ssh 远端、存档站、请用户提供原文）并询问用户。
- **任何跳过/降级必须走到「用户确认」或「用户拒绝后如实披露」**，写入合规账本（§4）。禁止单方判定后继续。

## 2. 证据隔离

- 第 3 章（汇编）的转述 = 待核查对象，不是证据；第 4 章（核查）不得引用第 3 章自身编号作证据（禁自我循环）。
- 每条裁决标注证据等级（facts.json `claims[].evidence_level`）：
  `1 官方文件/本人账号原文 ＞ 2 权威媒体全文 ＞ 3 转载引文 ＞ 4 搜索摘要/标题层`。
- 展示规则：verdict=「真实」且 evidence_level∈{3,4} 时，报告裁决显示「报道属实（原文未核）」
  （facts.json 语义不变，渲染层降级，由 build_report 执行）。

## 3. 标记域与裁决词

- ▲/●/△ 仅用于**具体数字/数据口径**（揽风云 4.4 既有规则，此处为联合报告执行声明）。
- 裁决 chip 只用裁决词：真实 / 部分真实 / 失实 / 证据不足（外加渲染降级变体「报道属实（原文未核）」），
  **chip 内禁止混入 ▲●△**（门禁 G3）。
- 否定性主张（"未见 / 未回应 / 未表态"类）默认裁决「证据不足」并注记"检索未见支持证据"；
  仅当存在权威渠道明确否定声明时可判「真实」（门禁 G5）。

## 4. 采集合规账本（compliance.json）

装配时以 `build_report.py --joint --compliance data/{event_id}/compliance.json` 渲染进第 7 章
（`<table class="compliance">`）；schema：

```json
[{"platform": "weibo", "status": "已采|跳过|降级", "block": "P|C|E|null",
  "escalated": true|false, "user_confirmed": true|false,
  "alternative": "dsh-ssh|存档站|用户提供原文|null", "note": "…"}]
```

- 状态非「已采」且无用户确认 = 不合规（门禁 G1）。
- 联合报告须在 `<head>` 带 meta：`<meta name="dsh-report" content="joint;contract=joint-v0.1">`
  （build_report `--joint` 自动注入；手写 HTML 须自行声明，门禁 G2）。

## 5. 统一时效

- 事件状态 = 进行中：走势/舆论章只允许情景句（"若官方不回应则 X；若双方继续发文则 Y"），
  禁止确定性曲线表述（回落 / 平息 / 结束等，门禁 G6）；并注明为动态快照。
- 成稿时间晚于信息截止 > 2 小时，须记录期间是否做过增量检索及结果。
- 背景/历史坐标（距今 > 1 年）须带时效核验标注：数据年份 + 其后是否检索到政策/事实变更 +「系既往回应 / 非现状」。

## 6. 断言登记册与前置扫描（执行一次）

- 核查阶段输入 = 汇编正文的断言清单（破虚妄阶段 2 本会做断言抽取，登记册天然形成，不新增流程）。
  F 表须覆盖登记册每条或给出显式豁免；豁免清单单列于覆盖声明。
- 诱因三问（① 有无触发事件；② 主张是否只有被媒体截取的半句；③ 有无断章取义警示信号）
  在登记断言时执行一次，结论写入 facts.json context 字段，供各阶段读取，不重复执行。

## 7. 交付质量门

装配后必跑：`python "~/.dsh/report-theme/check_report.py" --joint --strict <report.html>`，0 error 才可交付。
联合任务附加检查：G1 合规账本 · G2 联合 meta · G3 chip 混入 ▲●△ · G4 真实但证据 ≤ 转载层 ·
G5 否定性主张判真实 · G6 进行中事件确定性走势；GW 为人工复核清单（静态提示）。
任一 error 即拒收并回退对应阶段修复；禁止把 error 降级成脚注交付（确有异议可用 `--allow <id>` 显式豁免并记录理由）。
