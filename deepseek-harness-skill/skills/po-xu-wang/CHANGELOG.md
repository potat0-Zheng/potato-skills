## v2 (2026-09-12) — 结构健康修订（只动结构，不动方法论）

**背景**：SKILL.md 经数十轮追加后有 633 行 / 10 个 `##` / 24 个 `###` / 19 个 `####`，
而职责只有"抽断言 → 裁决"两步。同一份长沙「4岁男童被指摸臀」联合报告暴露出：
`facts.json` 的字段表在文档里只是"最小示例"、实物多出 5 个顶层字段；证据等级被当成
"我这次抓到没抓到"的度量；唯一的口径冲突整段消失；律师意见被判「真实」；第三章判
「证据不足」的 77 元在第二章被当事实直陈。以上全部无门禁可查。

**改动**：

1. **`facts.json` 的 schema 唯一权威移入 `CONTRACT-joint.md §11`**（与 ② 的工件同处），
   本文档删掉 JSON 示例块，改为一张"事项 → 依据"表。此前示例与实物脱节，
   导致 `event`/`as_of`/`context` 三个字段无人消费、`conflicts`/`ref` 两个字段无定义。
2. **证据等级口径澄清（契约 §2）**：等级量的是"证据本身是什么形态"，
   不是"本次核验取得了什么"；"我这次没抓到原文全文"不构成降级理由。
   并禁止在证据条目里写抓取动作（"（原文抓取）"），抓取事实由 `sources.json.fetched_file` 承载。
   实测首份报告 27 条断言中 6 条（22%）挂着「报道属实（原文未核）」，其中多为一手受访与基层口径。
3. **断言登记规则四条（契约 §3/§6）**：① 评价性 / 法律定性 / 因果推断 / 证明力评价
   **不进断言登记册**；② 否定性主张必须以否定句登记；③ 一条断言只承载一个可独立裁决的主张
   （给出可判据：含两个以上可分别裁决的子句即须拆条）；④ 裁决必须回写叙事——
   `证据不足 / 失实` 的具名数字不得在第一、二、五章直陈（新增门禁 R5）。
4. **联合态九章去向表（契约 §11 首段）**：把 verify 九章逐条映射到字段，
   或明确"由 ④ 的某章承担 / 不做"，终止"矛盾表与观点辨析静默消失"。
   新增 `facts.json.opinion_analysis` 字段 + 报告新增「观点辨析与推理说明」一章。
5. **联合态只走 `verify`**：`compile` / `timeline` 是独立态模式，与 ② 揽风云职责重叠，
   同时启用会产生"谁写汇编"的歧义。
6. **阶段 0 探活改为探真正要调的端点**（`so.news.cn` / `s.weibo.com` / `www.qcc.com` /
   `www.thepaper.cn` 等，来自工具源码），并把探活结论分三档（可用 / 凭证类 / 不可达）。
   旧模板测的是 `www.piyao.org.cn`——`china_sources.py` 从不访问的域名。
7. **阶段 3 的硬矛盾按断言类型分流**：原「中文语境必须至少调用一次 china_sources」与
   「不匹配就跳过」互相矛盾，靠"写个理由"缝合，等于空转。改为：带
   `rumor`/`social_media`/`enterprise` 标签必须调用；**事件经过类属默认豁免**，登记即可。
8. **回退链补齐为四级**（L1 curl → L1b 存档站 → L2 摘要层 → L3 用户粘贴）：
   原表写"三级、不可跳过"，正文却在 L2 前插了存档站，README 也写四级，三处不一致。
9. **路径与工具名残留清理**：`${SKILL_DIR}` 占位写法废止（与"不再用环境变量"自述矛盾，
   且三处仍在用）；`WebFetch` → `pwsh`+`curl`、`TaskOutput` → `job_output`（DSH 无前两者）。
10. **README 瘦身 + 删掉一处重复**：README 的手写"维护记录"（停在 2026-05-15，而 SKILL.md 最后改于
    2026-09-09）删除，版本与变更统一到本文件；`内置工具 → export_docx.py` 里那份 50 行示例代码删除
    ——`tools/export_docx.py` 末尾本就有两段示例，SKILL.md 抄了一份，属"同一份内容两处维护"。
    本轮净结果：**SKILL.md 633 行 → 615 行**（改动以替换与合并为主，未以新增段落换效果）。
