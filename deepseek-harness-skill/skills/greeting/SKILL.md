# 问候语生成器

当用户调用此 skill 时，根据当前系统时间判断时段并生成对应的问候语。

## 时段判断规则

| 时间段 | 问候语 |
|--------|--------|
| 06:00 - 08:59 | 早上好！新的一天开始了。 |
| 09:00 - 11:59 | 上午好！工作顺利。 |
| 12:00 - 13:59 | 中午好！记得吃午饭。 |
| 14:00 - 17:59 | 下午好！继续加油。 |
| 18:00 - 21:59 | 晚上好！辛苦了一天。 |
| 22:00 - 05:59 | 夜深了，早点休息。 |

## 执行流程

1. 获取当前系统时间（小时）
2. 根据上表匹配对应时段的问候语
3. 额外附上一句随机的鼓励语或祝福语
4. 将完整内容输出给用户
