## v6 (2026-09-12) — 结构健康修订（只动结构，不动方法论）

**背景**：SKILL.md 经数十轮追加后，联合任务依赖的四个工件无 schema、来源分级存在两套同名不同义的定义、
规则副本散在 5 个文件、失效引用与死代码并存、版本线并行——结构处于黑箱状态，只能靠产出倒推功效。

**改动**：

1. **接口定义（本次核心）**：工件 schema 的**唯一权威移入 `CONTRACT-joint.md §11`**
   （`timeline.json` / `sources.json` / `coverage.md` / `viewpoint.md`）。SKILL.md 只写"产出什么 + 两条硬纪律"，
   不复制字段表——此前 `actors.json`/`stance_cards.json` 有 schema 而另四个没有，模型只能即兴发挥，
   这是"时间线无年份 / 来源分级 A=0 / 覆盖声明漏剔除量"的共同来源。
2. **来源分级统一**：删掉本文档里那套 A=一手公报/B=权威媒体/C=商业媒体，改为指向 `CONTRACT-joint §2`
   （A=官方一手/本人账号原文 · B=权威媒体全文 · C=转载/自媒体/平台样本）。同名 A/B/C 曾有两套不同含义，
   直接产出过"来源共 86 条 · A 官方 0 条"的假统计，而正文实际引用了官媒原文。
3. **双路显式化**：新增「两条路径」一节，标明阶段 1–5 为两态共用、阶段 6/7 为联合态工件层。
4. **副本降级**：删掉本文档的「立场卡组书写限制」表（5 处副本之一），改为指向 `report-theme/CONTRACT.md`。
5. **引用修正**：`CONTRACT-joint §9` → `§8`（§9 已改为舆论口径）；顺带全量核验引用目标。
6. **脚本适用性声明**：新增「脚本适用路径」表，标明 `fetch_page.py` / `collect_images.py` / `embed_image.py`
   在联合态不适用（由 ① 采集链路负责）——实测它们在联合任务中从未被调用。
7. **新增结构体检脚本**：`scripts/audit_skill.py`，输出五张清单（规则多副本 / 失效引用 / schema 覆盖率 /
   脚本使用 / 版本标记）。**此后每次改 SKILL.md 或契约，以它的输出差异作为"改动是否生效"的证据**，
   不再靠人肉 grep。

**方法论零改动**：compile/timeline 双模式、5 阶段流程、主题聚类、去重合并、冲突消解、立场均衡、
确定性标记的用法均未改。本次只做"接线"，不新增任何分析方法。

**未完成（下一轮）**：独立态入口声明与引擎归属、阶段 6/7 在独立态的下位形态、独立 markdown 的质量门。

## v5 (2026-08-18) — DSH 适配 + 渐进式披露瘦身

**背景**：技能从 Claude Code 迁移至 DSH 后，存在路径硬编码、bs4 依赖缺失、L1（WebFetch 域名验证）假设残留等问题；且 286 行 SKILL.md 中约 44% 为条件触发的外媒清单，每次调用全量注入挤占上下文。

**改动**：

1. **frontmatter**：新增 `model: deepseek-v4-pro`（对齐同族 po-xu-wang）。
2. **渐进式披露瘦身**：SKILL.md 286 → ~135 行，将条件触发内容迁出为按需加载的 references：
   - `references/foreign-media.md` — 原「外媒信源清单与获取策略」整章（逐字迁入，加 DSH 语境注记）
   - `references/source-fallback.md` — 原「信源获取失败应对」，L1 由「Claude Code 域名验证」改写为「搜索零命中」应对
   - `references/html-export.md` — 原「导出→HTML」细节 + 图像选取标准
3. **脚本工程化**：脚本平移到 `scripts/`；`fetch_page.py` 重写为纯标准库（`html.parser` + urllib 回退，去除 bs4 依赖）。
4. **路径修复**：全部改为 `{SKILL_DIR}` 相对引用；知乎脚本 `../知乎` → `../zhihu`；Word 导出 `..\破虚妄` → `..\po-xu-wang`。
5. **执行环境契约**：新增 DSH/Windows 契约（UTF-8 写文件、`$env:PYTHONIOENCODING`、JSON 参数落盘）。
6. **资产**：`report_template.html` 平移至 `assets/`。

**方法论零改动**：compile/timeline 双模式、5 阶段工作流、引用编号体系、来源分级 A/B/C、确定性标记 ▲/●/△、7 章输出规范、三条「禁止」均逐字保留。
